## Mod compatibility
- Oculus Flywheel Compat 1.0.3b: loads, shadows work, Photon 67-81 -> 90-110 FPS near Create builds (uncapped); shaders off 227-258
  FPS (baseline 246), so no cost without shaders; only its own harmless "@Final field should be final" warnings.
- Known crash (not ours): turning shaders on inside a world with Flywheel Compat -> EXCEPTION_ACCESS_VIOLATION in
  `top.leonx.irisflw.vertex.block.ExtendedBlockWriterUnsafe.writeVertex`; it picks its 52-byte reader/writer live from
  `isShaderPackInUse()` and reads a model buffer built in the 32-byte format. Workaround: switch shaders at the title screen.
- Intermittent crash on Save and Quit: `NoClassDefFoundError: DhApiWorldUnloadEvent` in DH's `SharedApi.setDhWorld` (class is in the
  jar). Not Oculus code; suspects Java 24 on Forge 43, Redirector/ModernFix, or DH.
